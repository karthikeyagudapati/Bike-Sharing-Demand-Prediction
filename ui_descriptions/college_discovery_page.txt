**College Shortlist/Discovery Page UI Description**

**1. Purpose:**
To enable students to effectively search, filter, explore, and shortlist potential colleges and programs based on a wide range of criteria. This page serves as the primary tool for college research.

**2. User Flow:**
*   User navigates to this page (e.g., via "Find Colleges" button on dashboard or main navigation).
*   User can type keywords in the search bar.
*   User can apply various filters (Country, Type, Budget, etc.) to narrow down results.
*   Results are displayed in a card view, updating dynamically as filters change.
*   User can sort the results.
*   User can click "View Details" on a college card to see more comprehensive information (opens a modal or a dedicated pane/page).
*   User can add or remove colleges from their personal shortlist directly from the cards.
*   User can navigate through multiple pages of results using pagination.

**3. Key Components:**

    **3.1. Header/Navigation Bar (Consistent with Student Dashboard)**

    **3.2. Search Bar:**
        *   **Placement:** Prominently at the top of the page.
        *   **Functionality:** Allows users to search by keywords such as:
            *   College Name (e.g., "University of California")
            *   Program (e.g., "Mechanical Engineering")
            *   City (e.g., "Boston")
        *   **Interaction:** Live search suggestions can appear as the user types. Search is triggered by pressing Enter or clicking a search icon.

    **3.3. Filters Section:**
        *   **Placement:** Typically a persistent sidebar (left or right) or a collapsible horizontal bar below the search bar.
        *   **Title:** "Filters"
        *   **Filter Controls:**
            *   **Country:**
                *   **Type:** Multi-select dropdown with search functionality within the dropdown.
                *   **Options:** List of countries (e.g., USA, Canada, UK, Australia, Germany).
            *   **Type (College):**
                *   **Type:** Radio buttons or a single-select dropdown.
                *   **Options:** "Government", "Private", "All".
            *   **Budget (Indicative Annual Tuition Fee):**
                *   **Type:** Range slider (e.g., "$10,000 - $50,000") or two input fields (Min Fee, Max Fee).
                *   **Currency:** Clearly indicated.
            *   **Program Type:**
                *   **Type:** Multi-select dropdown.
                *   **Options:** Common program types (e.g., MTech, MS, MBA, PhD, BSc, BA, Diploma).
            *   **Mode of Study:**
                *   **Type:** Radio buttons or a single-select dropdown.
                *   **Options:** "Online", "On-campus", "Hybrid", "All".
            *   **Intake Season:**
                *   **Type:** Multi-select dropdown.
                *   **Options:** Academic intakes (e.g., "Fall 2024", "Spring 2025", "Winter 2025", "Summer 2025").
            *   **Sort By:**
                *   **Type:** Single-select dropdown.
                *   **Placement:** Can be part of the filter section or near the top of the results display area.
                *   **Options:** "Relevance" (default), "Ranking (High to Low)", "Fees (Low to High)", "Fees (High to Low)", "Deadline (Soonest)".
        *   **Action Buttons:**
            *   "Apply Filters" (if filters are not applied dynamically).
            *   "Clear All Filters".

    **3.4. Results Display Area:**
        *   **Placement:** Main content area of the page.
        *   **Layout:** Primarily a **Card View**.
        *   **Information per College Card:**
            *   **College Logo:** Small, recognizable logo.
            *   **College Name:** Prominent text.
            *   **Program(s) Matching Criteria:** If search/filter was program-specific, list 1-2 matching programs. (e.g., "MS in Computer Science", "MS in AI").
            *   **Location:** City, Country (e.g., "Cambridge, USA").
            *   **Key Ranking:** A prominent ranking, if available (e.g., "QS World Ranking: #3"). Source of ranking should be clear or inferable.
            *   **Indicative Tuition Fee Range:** (e.g., "$30,000 - $40,000 /year").
            *   **Application Deadline:** Display if a specific program is in context or a general upcoming deadline. (e.g., "Fall Intake Deadline: Jan 15, 2025").
            *   **Buttons:**
                *   "View Details": Opens the Selected College Detail View.
                *   "Add to Shortlist" / "Remove from Shortlist": Toggles the college's shortlist status. Icon changes accordingly (e.g., heart outline vs. filled heart).
            *   **Categorization Label (Optional but Recommended):**
                *   **Text:** "Safe", "Moderate", "Ambitious".
                *   **Logic:** Based on a comparison of the student's academic profile (GPA, test scores) against the typical admission criteria of the college. Requires student data to be available.
                *   **Placement:** Corner banner or distinct label on the card.
        *   **Empty State:** If no colleges match the criteria, display a message like "No colleges found matching your criteria. Try adjusting your filters."
        *   **Loading State:** Visual indicator (e.g., spinner) when results are being fetched or updated.

    **3.5. Pagination:**
        *   **Placement:** Below the results display area.
        *   **Functionality:** Standard pagination controls (Previous, Next, Page Numbers) if the number of results exceeds what can be displayed on a single page.

    **3.6. Selected College Detail View:**
        *   **Trigger:** Clicking the "View Details" button on a college card.
        *   **Presentation:** Can be a full-screen modal overlay, a slide-in side pane, or navigate to a separate page. Modal or side pane is often preferred to keep the user in the context of their search results.
        *   **Content:**
            *   **Header:** College Name, Logo, Location.
            *   **Comprehensive University Info:**
                *   Detailed description/about section.
                *   Full address.
                *   Link to official university website (opens in new tab).
            *   **Programs Offered:**
                *   A searchable/filterable list of programs offered by the university, especially those relevant to the student's profile or initial search.
                *   For each program: Name, Duration, Specific Fees, Specific Eligibility Criteria.
            *   **General Eligibility Criteria:** Overall academic requirements, language proficiency (e.g., TOEFL/IELTS minimums).
            *   **Visa Friendliness / Work Permit Stats (Country-Specific):**
                *   Information about student visa success rates, post-study work permit options and duration for the country where the college is located.
            *   **Ranking Details:**
                *   List of rankings from multiple sources if available (e.g., QS, Times Higher Education, US News) with specific subject rankings if relevant.
            *   **Return on Investment (ROI) Prediction (If Available):**
                *   Estimated potential earnings or career prospects after graduation. This is an advanced feature and may rely on third-party data.
            *   **Action Buttons within Detail View:**
                *   **"Apply Now":** Links to the university's official application portal (external link) or an internal application form if the platform has direct integration.
                *   **"Add to Calendar/Reminder":** Allows users to add important deadlines related to this college/program to their personal calendar or set a reminder within the platform.
                *   **"Request SOP Draft" (If Applicable):** If the platform offers SOP assistance services, this button could initiate a request related to this specific college/program.
                *   "Add to Shortlist" / "Remove from Shortlist" (if not already done from the card).
            *   **Close Button:** To close the modal/pane and return to the search results.

    **3.7. Footer (Consistent with Student Dashboard)**
